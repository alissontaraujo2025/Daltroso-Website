# Direção Tipográfica — Daltroso Advocacia

A imagem da hero serve como referência visual, mas não deve ser usada para adivinhar a fonte exata.
A tipografia do projeto deve ser definida explicitamente para manter consistência entre design, motion e código.

---

## 1. Direção principal

A identidade tipográfica deve combinar:

- uma serifada editorial para títulos grandes
- uma sans-serif limpa para textos, menus e interface

O resultado deve transmitir:
- sofisticação
- autoridade
- elegância
- clareza
- contemporaneidade

---

## 2. Títulos principais

### Estilo desejado
Serifada editorial, elegante, de alto contraste, com presença forte em tamanhos grandes.

### Opções preferidas
1. Cormorant Garamond
2. DM Serif Display
3. Libre Baskerville
4. Playfair Display

### Uso
- Hero
- grandes frases de impacto
- títulos de seções fullscreen
- palavras-chave em transições

### Regras
- usar tamanhos grandes
- evitar peso excessivo
- priorizar respiro
- evitar aparência clássica demais ou institucional demais
- não usar caixa alta em todos os títulos

---

## 3. Textos, menus e interface

### Estilo desejado
Sans-serif limpa, contemporânea e discreta.

### Opções preferidas
1. Inter
2. Manrope
3. Montserrat
4. Source Sans 3

### Uso
- menus
- botões
- textos corridos
- labels
- microcopy
- navegação
- informações auxiliares

---

## 4. Combinação inicial recomendada

### Opção A — mais editorial
Cormorant Garamond + Inter

### Opção B — mais sofisticada e limpa
DM Serif Display + Manrope

### Opção C — mais clássica, porém contemporânea
Libre Baskerville + Inter

Para o primeiro protótipo, usar preferencialmente:

**Cormorant Garamond para títulos**  
**Inter para interface e textos**

---

## 5. Hierarquia sugerida

### Hero principal
- serifada
- muito grande
- forte contraste
- entre 8vw e 11vw no desktop
- line-height aproximado entre 0.85 e 0.95

### Títulos de seção
- serifada
- entre 5vw e 8vw
- line-height compacto

### Subtítulos
- sans-serif
- entre 20px e 32px no desktop
- peso regular ou medium

### Texto corrido
- sans-serif
- entre 16px e 20px
- line-height confortável

### Menu
- sans-serif
- entre 14px e 18px
- espaçamento leve entre letras

---

## 6. Motion tipográfico

A tipografia deve participar das transições.

Usar:
- reveal por máscara
- entrada vertical suave
- fade combinado com deslocamento
- pequenas mudanças de escala
- transições sincronizadas com o scroll

Evitar:
- letras voando
- distorções exageradas
- animações rápidas
- efeitos 3D desnecessários
- excesso de tracking animado

---

## 7. Regra importante

A imagem `hero-daltroso-reference.png` é referência de composição, escala e sensação tipográfica.

Ela NÃO define automaticamente a fonte final.

O Claude Code deve seguir este arquivo para tipografia até que uma família final seja aprovada.
