# Daltroso Website Experimental

Projeto experimental para o novo site da Daltroso Advocacia e Consultoria Jurídica.

## Objetivo
Criar um site jurídico autoral, sofisticado, editorial e interativo, evitando a aparência de template tradicional de advocacia.

## Conceito
**Mais que consultoria. Inteligência jurídica.**

## Princípio de navegação
O site deve funcionar como uma sequência de cenas conectadas pelo scroll. Cada cena precisa nascer visualmente da anterior, usando luz, movimento, tipografia, enquadramento e transições como elementos de continuidade.

## Direção visual
- premium
- cinematográfica
- editorial
- humana
- sofisticada
- contemporânea
- clara
- sem excesso de efeitos

## Ferramentas previstas
- Claude Code com Opus
- geração de imagens por IA
- Kling e/ou Higgsfield para motion
- front-end com animação por scroll

## Ordem de trabalho
1. Planejar cenas
2. Aprovar direção visual
3. Gerar imagens-base
4. Gerar animações
5. Definir transições
6. Implementar front-end
7. Refinar responsividade e performance

## Regra principal
Não começar a implementação completa antes da aprovação do fluxo visual das cenas.
