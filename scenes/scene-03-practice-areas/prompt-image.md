# Cena 03 — Prompt de imagem

Create a fullscreen interactive section concept for a premium law firm website showing practice areas.

The visual should be clean, sophisticated and editorial.
Use strong typography as the main element.
Practice areas:
- Criminal
- Cível
- Família
- Digital

Concept:
one area should dominate the screen at a time.
The background should feel refined and atmospheric, changing subtly according to the active area.
Leave room for hover or scroll-based transitions.

Avoid generic legal cards.
Avoid cliché icon grids.
This should feel like a cinematic, interactive section, not a traditional services block.
