# Cena 04 — Prompt de imagem

Create a fullscreen editorial section for a premium law firm website explaining its method.

Key words:
- Ouvir
- Analisar
- Estruturar
- Defender

The visual should be driven by large typography, clean spacing and elegant hierarchy.
The section should feel sophisticated and intelligent, with room for short supporting text.
Avoid generic process icons.
Focus on typographic rhythm and clarity.
